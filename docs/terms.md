# 术语表

界面、文档、注释、报错里同一个概念只用这里的叫法。代码标识符保留英文原名，不必与界面叫法对应。枚举取值的中文名以 `shared/src/enums.ts` 里的 `*_LABEL` 为准，这里不重复。

## 作品与内容

| 界面叫法 | 代码 | 指什么 |
| --- | --- | --- |
| 作品 | `project` | 一部剧，名下有原文、资产与分集 |
| 原文 | `project_sources` | 导入的小说文本，一份原文可以分为多集 |
| 集 | `episode` | 一集短剧 |
| 叙事节拍、节拍 | `beat` | 一集改编后的剧情单元，台词在这一步定稿 |
| 分镜、镜 | `shot` | 一个镜头，首帧、视频、配音都按镜生成 |
| 合成版 | `film` | 一集按镜序拼接后的成片 |

## 资产与图

| 界面叫法 | 代码 | 指什么 |
| --- | --- | --- |
| 资产（角色、场景、道具） | `asset` | 需要固定形象、在多个镜头里反复出现的东西 |
| 锁定版 | `asset_versions` | 资产确认后的版本，分镜引用的是它，不是资产的当前编辑状态 |
| 换装 | `outfit` | 同一角色的另一身装扮，外貌与声音沿用本体的锁定版 |
| 设定图 | `asset_files` | 资产的标准图，每种一张，之后每一镜都照它画 |
| 设定图类型 | `AssetFileRole` | 全身、半身特写、三视图等 |
| 参考图 | `refs` | 生成某一镜时随请求带上的图，取自设定图或上一镜末帧 |
| 试音 | `voice_sample` | 角色的一段示范录音，参考图模式下随视频请求带上 |
| 音色描述 | `voice` | 角色声音的文字描述 |
| 首帧 | `first_frame` | 一镜的第一帧画面，视频从它往下演 |

## 生成

| 界面叫法 | 代码 | 指什么 |
| --- | --- | --- |
| 分集、提取资产、写节拍、拆分镜、审查、分镜提示词 | 模板 id 见 `PROMPT_IDS` | 调用文本模型的各个步骤 |
| 分镜提示词 | `shot_prompt` | 一镜的成品提示词：`image_prompt`、`motion_prompt`、`sound` 与台词念法 |
| 画面来源 | `clip_source` | 视频从首帧往下演，还是直接拿参考图生成 |
| 声音来源 | `audio_mode` | 视频自带声音，或单独配音后在合成时叠加 |
| 过时 | `stale` | 上游改动后，照旧内容做出的产物 |

## 模型接入

| 界面叫法 | 代码 | 指什么 |
| --- | --- | --- |
| 接口 | `endpoint` | 一份接口定义：请求模板、轮询与取结果的方式。Base URL 与凭证另配，同一接口可以接到不同地址；注释里沿用「端点」 |
| 模型类别 | `BindingRole` | 文本、图像、视频、配音四类，每类绑定一个接口、模型与凭证 |
| 用途 | `purpose` | 一次调用是为哪一步发起的，任务记录按它筛选 |
| API 凭证 | `credentials` | Base URL 与 API Key 的组合，展示时脱敏 |
| 供应商 | — | 提供模型服务的公司 |
| 模型 | `model` | 接口下具体调用的模型名 |
